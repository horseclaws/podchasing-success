How deep should the redesign go?

The app already uses the right brand colors. The question is how much of the new design system to apply.

A

Accent Layer

Fix off-brand colors (blue spinner, blue Run button). Apply HeroSummary to page headers. Leave existing cards and layouts as-is.

Fastest. Low risk. Focused visual upgrade at the top of each page.

B

Component Refresh

Everything in A, plus: wrap all white cards as InsightCard, use CalloutBlock for AI Summary, PillBadge for status/tier labels, StatGrid for deal metrics. Consistent tokens throughout.

Moderate effort. Makes the whole app feel unified and intentional.

C

Full System

Everything in B, plus: convert all inline style={{}} props to Tailwind CSS variable classes, standardize spacing scale, redesign the nav bar to use the deep-violet color.

Largest effort. Cleanest codebase. Every pixel on-system.
